# Proyecto de Aula Invertida: Servidor DHCP en Linux

**Módulo:** Servicios de Red e Internet
**Autores:** Alejandro Álvarez Romero y Hugo Pérez Arévalo
**Curso:** 2024/2025

## 📋 Descripción
Este repositorio contiene todo el material necesario para impartir la sesión sobre **Instalación y configuración de DHCP (ISC-DHCP-SERVER)**.

## 🗂️ Estructura del Proyecto

* **/presentacion**: Diapositivas teóricas y paso a paso.
* **/material_aula_invertida**: Vídeo tutorial y hoja de trucos (Cheatsheet).
* **/actividades**: Prácticas para los alumnos (Básica y Avanzada).
* **/kahoot**: Preguntas para el concurso interactivo.
* **/examen**: Prueba objetiva de evaluación.
* **/guia_profesor**: Manual para impartir la clase.

## 🚀 Tecnologías
* **SO:** Linux (Debian/Ubuntu/Kali)
* **Servicio:** isc-dhcp-server
* **Protocolo:** UDP 67 (Server) / 68 (Client)
